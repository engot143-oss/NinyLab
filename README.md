# NinyLab

Niny's local Python desktop companion: petting, six moods, gentle floating,
idle naps, compact mode, dragging, and saved preferences.

## Open Niny on Windows

1. Download this repository using **Code → Download ZIP**.
2. Right-click the downloaded ZIP and choose **Extract All**. Use a new folder
   so your existing working Niny stays safe. Keep the extracted folder.
3. Open that folder and double-click **Launch Niny.vbs**. First-time setup runs
   automatically and requires Python 3 installed with tkinter and the Python
   launcher (`py`). Later launches run without a console.
4. Click **Choose Niny image…** and select your existing `niny.png`. Niny
   remembers the picture without moving or changing it.
5. Optional: double-click **Create Niny shortcut.vbs** for a desktop shortcut.

Pet Niny with the button or by clicking her. Drag her picture to move the
window. Right-click for mood choices and settings. **Compact companion** hides
the controls; right-click again to restore them. Close the window to exit.

The approved picture is not bundled yet. Original uploaded v0.1/v0.2 code is
preserved in `originals/`. GUI checks passed on Linux; Windows launcher,
installation, and shortcut creation still need verification on Windows.

See [Windows launch details](WINDOWS-LAUNCH.md) for troubleshooting.
